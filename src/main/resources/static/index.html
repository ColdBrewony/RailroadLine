      기본 지도는 회색 연결망으로 표시하며 공유 구간은 한 번만 그립니다. 노선 목록에서 선택하거나 지도에서 노선의 선을 클릭하면 해당 노선의 전체 경로가 고유 색으로 나타나고 오른쪽(모바일은 하단) 패널에 역 목록·거리가 표시됩니다. 다시 선택하거나 '전체 보기'를 누르면 해제됩니다. 역을 클릭하면 같은 패널에서 소속 노선·이전/다음역·구간거리·KTX 정차 여부를 확인할 수 있습니다.
