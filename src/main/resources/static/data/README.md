# korea-outline.json

배경 지도로 까는 대한민국(본토+제주, 울릉도/독도 제외) 윤곽선입니다. 역 좌표와 똑같은 좌표계로
미리 투영해 둔 정적 자산이라 서버 계산 없이 프론트에서 바로 배경으로 그릴 수 있습니다.

## 출처

[southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps) 저장소의
`kostat/2013/json/skorea_provinces_geo.json`(통계청 2013년 행정구역 경계, **단순화 안 된
원본 해상도**, 약 28MB). 처음에는 저장소가 같이 제공하는 `_geo_simple.json`(단순화된 버전,
약 150KB)을 그대로 썼는데, 화면을 깊이 확대했을 때 해안선이 너무 뭉툭하게 각져 보여서(특히
남해안처럼 섬이 많은 구간) 원본 해상도로 바꾸고 직접 단순화하는 쪽으로 교체했습니다. 이
저장소는 라이선스를 명시하지 않았습니다 — 내부 도구용 배경 참고 이미지로만 쓰고, 공개 배포
시에는 라이선스가 명확한 다른 출처(예: Natural Earth, 공공데이터포털의 행정구역 경계)로
교체하는 걸 권장합니다.

## 생성 방법

`scripts/build-korea-outline.py`가 이 파일을 만듭니다. 원본 GeoJSON(28MB, 저장소에는 커밋하지
않음 — 스크립트가 매번 새로 내려받음)의 각 폴리곤 바깥 고리(ring)를 `GeoAnchorCalculator`가
역 위경도를 투영할 때 쓰는 것과 **완전히 동일한 고정 범위·공식**(위도 33.0~38.65, 경도
124.5~129.6, cos 보정 후 종횡비를 유지한 채 캔버스에 맞춤)으로 먼저 투영한 다음, 투영된
좌표계 기준으로 Douglas-Peucker 알고리즘을 적용해 브라우저가 그리기 적당한 크기로 줄입니다
(기본 허용오차 1.5px, 이보다 작은 섬은 통째로 버림 — 기본 최소 넓이 3제곱px). 그 결과
`[[ [x,y], ... ], ...]` 형태의 좌표 배열로 저장됩니다(원본 62만여 점 -> 약 1만 2천 점,
488개 고리). 본토·제주 범위(경도 129.6) 밖에 있는 울릉도 등은 제외됩니다.

`GeoAnchorCalculator`의 고정 범위 상수를 바꾸면 이 파일도
`python scripts/build-korea-outline.py`로 반드시 다시 생성해야 역 좌표와 정렬이 어긋나지
않습니다.
