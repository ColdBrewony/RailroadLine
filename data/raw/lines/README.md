# 수집 데이터 검토 가이드 (v2 — 위키백과 전수 검증 완료)

이 폴더는 처음에는 `docs/assets/korail-railroad-map-2026-01-01.jpg`에서 추출했고, 이후 **한국어 위키백과(ko.wikipedia.org)의 각 노선별 문서를 노선마다 하나씩 대조·정정**한 데이터입니다. 69개 파일 전부 `"source": "ko.wikipedia.org"`로 표시되어 있으며, 모두 위키백과 기준으로 검증되었습니다.

## 전체 현황

- **69개 노선 파일** (기존 65개 + 작업 중 신규 발견 4개: 보성연결선, 가은선, 전경삼각선 — 그 외 1개는 기존 파일 분리)
- **839개 역-노선 행(row)**
- 지도 판독 단계에서 있었던 오류 다수 정정됨(아래 "주요 정정 사항" 참고)

## 상태 플래그

일부 노선은 `"status"` 필드로 현재 운행 상태를 표시합니다:

| 상태 | 의미 | 해당 노선 |
|---|---|---|
| `CLOSED` | 완전 폐선 | 군산화물선(2022년), 가은선(2004년) |
| `SUSPENDED` | 여객 영업 중지(선로는 존재) | 문경선, 진해선 |
| `UNBUILT` | 아직 준공/미개통 | 동해북부선(제진-감호) |
| (없음) | 정상 운행 중 | 나머지 대부분 |

## 아직 완전히 일치하지 않는 항목 (`verification.match: false`)

| 파일 | 내용 |
|---|---|
| `군산항선.json` | 위키백과 개요의 "영업거리 28.6km"와 정차역 표 마지막 값(25.8km)이 위키백과 자체에서 서로 다름 |
| `중앙선.json` | 개요의 공식 총거리(331.3km)와 역간거리 누적 합산(323.0km) 사이 8.3km 차이 — 위키백과 자체 불일치로 추정 |

둘 다 제가 만든 오차가 아니라 **위키백과 원본 안에 있는 불일치**이며, `sourceNotes`에 설명해뒀습니다.

## 이번 위키백과 검증으로 드러난 주요 정정 사항

- **역명 오독 정정**: 진해선 "충리→중리", 호남선 "요산→연산", "대신→논산", 경전선 "충리(중리 아님, 별도)", 태백선은 역명 전체가 한 칸씩 밀려 있었음(입석리/쌍룡/연당 등)
- **기점 오류 정정**: 덕산선(용강→창원), 북전주선(전주→동산), 신동화물선(신동→지천), 울산신항선(동해선분기→망양), 평택선(순서 반전)
- **종점 오류 정정**: 묵호항선(묵호항→묵호가 실제 종점), 함백선(함백→조동이 실제 종점)
- **뒤바뀐 값**: 신항남선/신항북선 거리가 서로 뒤바뀌어 있었음
- **완전히 비어있던 구간 대량 보강**: 장항선(화양 이후 전체), 호남고속선(전체), 중앙선(청량리~원주 전체), 수인선(2개 역→28개 역), 동해선(포항·경주 등)
- **새로 발견한 노선 4개**: 보성연결선, 가은선(폐선), 전경삼각선, (온산선 등 기존 파일 보강 중 확인)
