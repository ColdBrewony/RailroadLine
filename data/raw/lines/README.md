# 수집 데이터 검토 가이드 (v3 — 최종)

이 폴더는 `docs/assets/korail-railroad-map-2026-01-01.jpg`(KORAIL 전국 철도노선도)에 박스로 표기된 노선을 1차로 판독한 뒤, **한국어 위키백과(ko.wikipedia.org)의 노선별 문서와 전수 대조·정정**한 최종 데이터입니다.

## 전체 현황

- **68개 노선 파일**, 총 **839개 역-노선 행(row)**
- 68개 전부 `source` 필드에 출처 표기(대부분 `ko.wikipedia.org`, 일부는 지도와 위키백과 병기)
- 전체 JSON 문법 검증 통과(68개 전부 정상)

## 작업 이력

1. **1차**: 지도 이미지를 구역별로 크롭해서 육안 판독 (노선명·역명·거리)
2. **2차**: 노선 하나씩 위키백과 문서를 가져와 대조 — 역명 오독, 순서 오류, 누락 구간을 다수 정정
3. **3차**: 지도를 다시 전수 재검토해서 초기 판독에서 놓친 노선 확인
   - 위키백과 교차 확인 중 발견했지만 **지도에는 박스로 없는** 4개(가은선/경강선-원주강릉/보성연결선/전경삼각선)는 **삭제**
   - 지도에 박스로 있었는데 **1차 판독에서 놓쳤던** 3개(교외선/괴동선/영일만항선)는 **추가**

## 상태 플래그

일부 노선은 `"status"` 필드로 현재 상태를 표시합니다:

| 상태 | 의미 | 해당 노선 |
|---|---|---|
| `CLOSED` | 완전 폐선 | 군산화물선(2022년) |
| `SUSPENDED` | 여객 영업 중지(선로는 존재) | 문경선, 진해선 |
| `UNBUILT` | 아직 준공/미개통 | 동해북부선(제진-감호) |
| (없음) | 정상 운행 중 | 나머지 전부 |

## 아직 완전히 일치하지 않는 항목 (`verification.match: false`)

| 파일 | 내용 |
|---|---|
| `군산항선.json` | 위키백과 개요의 "영업거리 28.6km"와 정차역 표 마지막 값(25.8km)이 위키백과 자체에서 서로 다름 |
| `중앙선.json` | 개요의 공식 총거리(331.3km)와 역간거리 누적 합산(323.0km) 사이 8.3km 차이 — 위키백과 자체 불일치로 추정 |

둘 다 저희가 만든 오차가 아니라 **위키백과 원본 안에 있는 불일치**이며, 각 파일의 `sourceNotes`에 설명해뒀습니다.

## 위키백과 검증으로 바로잡은 주요 오류 (참고용)

- **역명 오독**: 진해선 "충리→중리", 호남선 "요산→연산"·"대신→논산", 태백선(역명 전체가 한 칸씩 밀려있던 것)
- **기점 오류**: 덕산선(용강→창원), 북전주선(전주→동산), 신동화물선(신동→지천), 울산신항선(동해선분기→망양), 평택선(순서 반전)
- **종점 오류**: 묵호항선(묵호항→묵호가 실제 종점), 함백선(함백→조동이 실제 종점)
- **뒤바뀐 값**: 신항남선/신항북선 거리가 서로 뒤바뀌어 있었음
- **완전히 비어있던 구간 대량 보강**: 장항선(화양 이후 전체), 호남고속선(전체), 중앙선(청량리~원주 전체), 수인선(2개 역→28개 역), 동해선(포항·경주·부조 등)

## 동명이역(같은 이름, 다른 실제 역) 구분

`Station.name`이 전체 역 중 유일해야 하는데(고유 제약), 서로 완전히 다른 지역의 실제 역이 우연히
같은 이름을 쓰는 경우가 있어 원래는 하나의 역으로 잘못 합쳐졌었다. 전체 데이터를 노선 간 지역
겹침 여부로 스캔해서 다음 2쌍을 찾아, 위키백과/코레일 안내의 동음이의 표기 방식을 따라
구분했다(원본 역명 자체를 바꿔치기한 것이므로 검색 결과에도 이 표기로 나타난다).

| 역명 | 노선 A | 노선 B | 구분 표기 |
|---|---|---|---|
| 구룡 | 분당선(서울, 강남) | 경전선(순천시 별량면) | `구룡(서울)` / `구룡(순천)` (위키백과 문서명) |
| 판교 | 경강선(성남) | 장항선(서천) | `판교(성남)` / `판교(서천)` (코레일톡 안내 표기) |

별개로 `경부고속선.json`에서 동대구~울산 사이 KTX 정차역이 `경주`로 잘못 기재돼 있던 것도
바로잡았다. 실제로는 경주 구시가지의 경주역(동해선)이 아니라 건천읍에 있는 별개의 역인
`신경주`가 KTX 정차역이다(위키백과로 확인) — 동명이역은 아니지만 같은 이유(역명을 혼동해
서로 다른 두 역을 하나로 합쳐버림)로 좌표가 크게 어긋났었다.

노선 간 지역 겹침 여부로 자동 스캔했을 때 `김천`도 걸렸지만(경부선 vs 경북선), 확인해 보니
경북선의 기점이 실제로 김천역이라 같은 역이 맞아서 그대로 뒀다 — 코레일 지역본부 구분이
노선마다 달라서 생긴 우연이다.

## 각 파일에서 확인할 필드

- `stations[].remarks`: "정정", "신규 확인" 등 문구가 있는 역은 변경 이력이 있다는 뜻
- `status`: 위 상태 플래그 표 참고
- `verification`: 위키백과 공식 총거리와 대조한 결과
- `segmentLabel`: 동일 노선명이 여러 구간으로 나뉜 경우(강릉선, 경강선, 서해선) 구간 구분자
