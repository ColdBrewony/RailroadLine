# 철도 노선도 웹 서비스 — 작업 로드맵

## 프로젝트 개요

- **원본 자료**: KORAIL 전국 철도노선도(2026.01.01 기준) 이미지. 실제 지리 좌표가 아닌, 노선/역/거리(km) 정보를 담은 도표형 지도.
- **목표**: 이 노선도를 지도 형태가 아니라 **지하철 노선도 스타일의 도식화된 다이어그램**으로 재구성하고, 역 이름으로 **검색**하면 해당 역이 속한 노선과 관련 정보(인접역, 거리, 역 종류 등)를 보여주는 웹 서비스를 만든다.
- **기존 프로젝트 골격**: Spring Boot 4.1.1 (Java 17), 패키지 `com.futek.railroad`. 프론트엔드 기술은 아직 미정이며 이후 단계에서 결정한다.

문서는 `docs/` 폴더 아래 단계별로 하나씩 순서대로 작성한다. 이 문서는 전체 작업 목록(로드맵)이며, 각 단계에 착수할 때 해당 상세 문서를 별도로 작성한다.

## Phase 0. 기획 및 요구사항 정리

- [ ] 서비스 범위 확정 — 전국 철도망(고속철도·일반철도·광역전철·화물선 등 107개 노선 전부) vs 우선순위 노선(여객 운행 노선 우선)부터 시작할지 결정
- [ ] 사용자 시나리오 정의 — 역 검색 → 소속 노선/인접역/거리 조회, 노선 선택 → 소속 역 목록 및 도식화된 노선 보기
- [ ] 화면 요구사항 정리 — 노선도 뷰, 검색창(자동완성), 역 상세 패널, 노선 범례
- [ ] 비기능 요구사항 정리 — 반응형(모바일 대응), 성능, 데이터 갱신(개정판 반영) 방식
- 산출물: `docs/01-requirements.md`

## Phase 1. 데이터 모델 설계

- [ ] 핵심 엔티티 설계: 노선(Line), 역(Station), 구간(Section/Edge, 역간 거리 포함), 운영본부(Region)
- [ ] 원본 범례 반영: 역 종류(관리역/고속열차 정차역/직원배치역/배치역/화물취급역/무인역/신호소/임시승강장), 선로 종류(단선/복선/비전철/광역전철 운행구간/고속철도 운행구간)
- [ ] 환승역(여러 노선이 만나는 역) 모델링
- [ ] **도식화 좌표계** 설계 — 실제 위경도가 아닌, 지하철 노선도처럼 정렬된 x/y 좌표를 노선별로 별도 정의
- [ ] DB 스키마 및 ERD 작성
- 산출물: `docs/02-data-model.md`

## Phase 2. 원본 데이터 구축

- [ ] 원본 이미지(`철도노선도(2026.1.1.).jpg`)에서 노선별 역 목록과 역간 거리를 추출 (수작업 입력 또는 OCR 보조 + 검증)
- [ ] 노선별 소속 운영본부, 노선 구분(고속철도/일반철도/광역철도/화물선 등) 정리
- [ ] 환승·분기역 식별 및 표기
- [ ] 구조화된 데이터 포맷(JSON/CSV 등)으로 1차 저장, 향후 DB 시딩에 사용
- 산출물: `docs/03-data-source.md` (데이터 추출 규칙 및 출처 정리) + 데이터 파일
