# 06. 검색 / 상세 정보 UI 설계

전제: `05-frontend-design.md`(바닐라 HTML/CSS/JS, `search.js`/`detailPanel.js` 모듈)를 기준으로 검색과 역 상세 패널의 세부 동작을 정의한다. F2(역 검색), F3(역 상세 정보)를 다룬다.

## 1. 전체 레이아웃 와이어프레임

### 1.1 데스크톱

```
┌───────────────────────────────────────────────────────────────┐
│ [ 🔍 역 이름 검색...            ]                 노선 필터 ▾   │
├───────────┬───────────────────────────────────────┬───────────┤
│           │                                       │  역 상세   │
│  노선 목록  │              노선도(SVG)                │  패널     │
│  사이드바   │                                       │ (선택 전   │
│  (F4)     │                                       │  에는 숨김) │
│           │                                       │           │
│           │                          [범례]         │           │
└───────────┴───────────────────────────────────────┴───────────┘
```

### 1.2 모바일 (좁은 화면)

```
┌───────────────────────────┐
│ [ 🔍 역 이름 검색...      ] │
├───────────────────────────┤
│                           │
│        노선도(SVG)          │
│                           │
│                           │
│                    [범례▾] │
└───────────────────────────┘
   (역 선택 시 하단에서 바텀시트 슬라이드업)
┌───────────────────────────┐
│  ▬▬  (드래그 핸들)          │
│  동대구                    │
│  경부선 · 경부고속선 · 대구선  │
└───────────────────────────┘
```

노선 목록 사이드바는 모바일에서 좌측 드로어(햄버거 버튼으로 토글)로 전환.

## 2. 검색 인터랙션 상세

### 2.1 입력 → 자동완성

- 입력 시작 후 **200ms 디바운스**, 최소 1글자부터 `/api/stations/search?q=`&limit=10` 호출.
- 자동완성 리스트는 검색창 바로 아래 드롭다운. 각 항목: `역명` + 소속 노선 배지(최대 3개, 초과 시 "+N").

```
┌─────────────────────────────┐
│ 동대                          │
├─────────────────────────────┤
│ 동대구   [경부선][경부고속선][+1] │
│ 동대전   [경부선]              │
└─────────────────────────────┘
```

- **키보드 내비게이션**: ↑/↓로 항목 이동(선택 항목 하이라이트), Enter로 확정, Esc로 드롭다운 닫기. 마우스 클릭도 동일하게 동작.
- 결과 없음: "검색 결과가 없습니다" 문구를 드롭다운 자리에 표시(빈 배열 응답 처리).
- API 에러 시: 드롭다운에 "검색 중 오류가 발생했습니다" 표시, 콘솔에 상세 로그(내부 도구이므로 사용자에게 기술적 에러 메시지 노출은 최소화).

### 2.2 검색 결과 선택 시 동작

1. `/api/stations/{id}` 호출
2. `state.js`의 `selectedStationId` 갱신 → 이를 구독하는 `diagram.js`, `detailPanel.js`가 각자 다시 그림
3. `diagram.js`: 해당 역 좌표로 팬 이동(좌표 없는 Stage A 뷰인 경우, 해당 역이 포함된 노선 뷰로 전환) + 역 마커에 하이라이트 클래스 부여
4. `detailPanel.js`: 아래 3절 레이아웃대로 상세 정보 렌더링, 데스크톱은 우측 패널 표시, 모바일은 바텀시트 슬라이드업

## 3. 역 상세 패널 레이아웃

```
┌───────────────────────────────┐
│  동대구                    [✕] │
│  🚉 관리역 · KTX 정차   대구본부  │
├───────────────────────────────┤
│  경부선                         │
│   대구 ── 4.0km ── [동대구] ──  │
│                     9.1km ── 지천 │
├───────────────────────────────┤
│  경부고속선                      │
│   … (이전역) ── [동대구] ──      │
│                    … (다음역)    │
├───────────────────────────────┤
│  대구선                         │
│   [동대구](기점) ── 5.3km ── 동촌 │
└───────────────────────────────┘
```

- 상단: 역명, 역 종류 아이콘(관리역/무인역 등), KTX 정차 여부 뱃지, 소속 본부.
- 본문: **소속 노선마다 카드 하나**, 이전역/현재역/다음역과 각 구간 거리(km) 표시. 기점/종점인 경우 이전 또는 다음이 없으므로 "(기점)"/"(종점)"으로 표기.
- 각 카드의 이전/다음 역 이름을 클릭하면 해당 역으로 상세 패널이 전환됨(연쇄 탐색 가능).
- 닫기 버튼(✕): 상세 패널 숨기고 하이라이트 해제.

## 4. 노선 목록 사이드바

```
┌───────────────────┐
│ [전체][KTX][일반][광역][화물]  ← category 필터 탭
├───────────────────┤
│ 경부선      441.7km │
│ 경부고속선   398.2km │
│ 호남선      252.5km │
│ …                  │
└───────────────────┘
```

- 상단 탭으로 `LineCategory` 필터(`/api/lines?category=`).
- 목록 항목 클릭 시 해당 노선을 노선도에서 하이라이트(05-frontend-design.md 4절 상호작용 흐름과 동일).
- 항목이 많으므로(전체 107개) 리스트는 스크롤 가능한 영역으로 구성, category 필터로 실질적으로 줄여서 탐색.

## 5. 범례(Legend) UI

- 원본 지도 범례를 웹 버전으로 재현: 역 종류 8종 아이콘 + 명칭, 선로 종류(단선/복선/비전철/광역전철운행구간/고속철도운행구간) 색상 샘플.
- 데스크톱은 노선도 우하단 고정, 모바일은 하단에 접이식(▾ 토글) 버튼으로 제공해 화면을 가리지 않게 함.

## 6. 접근성 (내부 도구 기준 최소 수준)

- 검색 입력창에 `aria-autocomplete="list"`, 드롭다운 항목에 `role="option"` 적용해 스크린리더 최소 지원.
- 노선도 SVG의 역 요소에 `<title>` 태그로 역명 툴팁 제공(마우스 hover 시 네이티브 툴팁).
- 색상만으로 정보를 구분하지 않도록(예: 노선 색상 외에 역 종류는 아이콘 모양도 함께 사용) — 범례 설계에 이미 반영.

## 7. 빈 상태 / 에러 상태

| 상황 | UI |
|---|---|
| 초기 진입(아무것도 선택 안 함) | 상세 패널 숨김, 노선도는 전체(또는 기본) 뷰 표시 |
| 검색 결과 0건 | 드롭다운에 "검색 결과가 없습니다" |
| 역 상세 API 실패 | 패널에 "정보를 불러오지 못했습니다" + 재시도 버튼 |
| 노선도 데이터(`/api/diagram`) 로딩 중 | 노선도 영역에 간단한 로딩 인디케이터 |
