## 2026-09-21 후속 갱신

이 문서의 "완료 범위"와 아래 진행표는 위 1차 수정 시점(50개 역 외부 대조) 기준으로 작성됐다.
이후 커밋 없이 진행된 후속 작업(다른 세션)에서 68개 노선 726개 역 거의 전부를 외부 출처와 대조했고,
`data/raw/station-coordinates-verified.csv`(726개 역 중 724개 검증), `data/raw/station-coordinate-full-audit.csv`(전체 726개 역의 상태 기록),
`data/raw/station-coordinate-audit.csv`(변경 로그)로 결과를 남겼다. 경부고속선 `신경주→경주`(2023년 개칭),
문경선 구역/중부내륙선 신역 분리(`문경(구역)`), 옥구선 `군산옥산신호장→군산옥산`, 영동선 `양원→양원(봉화)`(동명이역 분리)도 이때 반영됐다.
이 갱신 작업은 커밋되지 않은 상태로 남아 있었기 때문에 `git log`만으로는 진행 상황을 알 수 없었다 — 확인하려면
`git diff HEAD`와 아래 "진단 재생성" 명령을 직접 실행해야 한다.

같은 세션에서 위키백과 원문 직접 대조(사상·가야·범일·판교·문경·신둔도예촌·세종대왕릉·신갈 등)로 표본 검증했고,
전부 소수점까지 일치했다. 신갈역은 원본 위키 좌표가 인접 기흥역과 4.5km 떨어져 명시된 영업거리(1.4km)와 모순됨을 확인해
Rail.Blue 주소 좌표(기흥역과 약 1.3km, 영업거리와 부합)로 교정한 판단이 맞다는 것도 재확인했다.
남은 `pending` 4건 중 신치(위키데이터 Q1592790, 선평~정선 구간과 부합)와 안인(위키 좌표 없음 — OSM 화물야드 태그를
정동진·청량신호소 양쪽 영업거리와 교차검증해 해소)은 이번에 추가로 해소했다. 야음(폐역, 부지에 주유소/사거리만 남음)과
군산화물선분기(장항선 분기점이라는 설명 외 별도 역 문서 없음)는 신뢰할 만한 출처를 찾지 못해 여전히 `pending`이다 —
추측 좌표를 넣지 않고 미확정으로 남겼다.

## 완료 범위 (1차 수정 시점 — 아래 갱신 이후 내용은 위 절 참고)

**68개 노선 전체의 앵커 진단과 50개 역의 외부 출처 대조를 수행했다. 전체 역의 좌표 검증을 끝낸 것은 아니다.**
현재 JSON은 68개 파일, 이름으로 중복 제거한 역 727개다(수정 전 726개에서 구/신 문경역 분리로 1개 증가). 인계 문서의 823개와 차이가 있어 실제 파일 집계값을 사용한다.

가야선(3/3), 강경선(2/2), 강릉선(16/16), 경강선(12/12)은 각 역을 외부 좌표와 대조하고 모두 유효한 닻을 확보했다.
강경선은 현재 프로젝트가 나타내는 채운신호장~연무대 5.8km 구간 기준이며 신연무대 인입선까지 확장한 검증은 아니다.
정부 CSV에 없는 29개 역을 보충하고, 기존 오류/0좌표 8개는 Java 보정 맵으로 교정했다. 기존 218개 CSV 행은 그대로 보존했다.

역별 출처와 확인한 좌표는 [감사 CSV](../data/raw/station-coordinate-audit.csv)에 있다. 한국어 위키백과 역 문서의 좌표를 대조했고,
범일은 한국어 문서에 좌표가 없어 [영어 Korail 역 문서](https://en.wikipedia.org/wiki/Beomil_station_(Korail))를 사용했다.
도시철도와 동명인 역은 해당 철도공사 문서를 선택했다. 기존 좌표와 1km 미만 차이는 유지했다.

## 발견과 수정

1. 강릉선의 서원주·횡성·둔내·평창·진부(오대산)는 원본에 행이 있지만 좌표가 0/0이었다. CSV 존재 여부만으로 정상으로 판단할 수 없다.
2. 철암은 청량리 부근 좌표가 들어 있었다. 실제 철암 위치로 보정했다.
3. 여수엑스포는 전남본부 경도 상한 127.60 때문에 제외되고 있었다. 또한 원본과 현 역사 좌표는 약 1.08km 차이여서, 인계 문서의 '1km 미만이며 정확하다'는 결론도 수정한다. 여천 역시 약 1.44km 차이를 교정했다. 역사 이전 이력이 있지만 원본이 어느 시점의 좌표인지는 단정하지 않는다.
4. 김천 등 경북선 서쪽 역들도 경도 하한 128.20에 걸렸다. 해당 범위를 128.00까지 넓혀 기존 정상 좌표를 되살렸다. 문산·도라산의 위도와 여주의 경도도 지역 범위에 반영했다.
5. 공유역의 실측값이 다른 노선에서 제외되면 그 노선의 추정값과 평균되어 위치가 밀렸다. 이제 하나 이상의 소속 노선에서 검증을 통과한 실측 좌표는 최종 위치에 그대로 사용한다. 모든 소속 노선에서 제외된 값까지 무조건 신뢰하는 변경은 아니다.
6. 백마고지의 인계 문서 예시 좌표는 현재 [역 문서](https://ko.wikipedia.org/wiki/백마고지역)의 38.257368 / 127.165992와 다르다. 예시를 복사하지 않고 확인한 값을 추가했다.
7. 부발 보충으로 중부내륙선이 닻 2개가 되어 부발~충주 구간을 문경까지 외삽하게 되는 영향을 발견했다. 종점도 확인해 추가하고, 문경선 구역과 중부내륙선 신역이 같은 역으로 합쳐진 데이터를 분리했다. 신역은 [한국어 역 문서](https://ko.wikipedia.org/wiki/문경역)와 [Rail.Blue의 2024년 개업 역 좌표](https://rail.blue/railroad/logis/stationinfo.aspx?id=4821912&lang=en&v=d)를 교차 확인했으며 약 0.09km 차이다. 구역은 [Wikidata Q1597551](https://www.wikidata.org/wiki/Q1597551)의 36°43′46″N / 128°6′23″E를 사용했다.

## 우선 외삽 구간 결과

외삽 비율은 가장 가까운 끝쪽 닻 두 개의 인덱스 간격을 기준으로 한다. 0은 양 끝에 닻이 있다는 뜻이며 중간 역의 좌표 정확도를 보장하지 않는다.

| 노선 | 닻 수 전 → 후 | 최대 외삽 비율 전 → 후 | 조치 |
|---|---:|---:|---|
| 경북선 | 5 → 10 | 6.00 → 0 | 김천 등 기존 좌표 지역 검사 복구 |
| 경원선 | 2 → 7 | 4.714 → 0 | 광운대·의정부·동두천·연천·백마고지 보충 |
| 경의선 | 2 → 5 | 2.429 → 0 | 일산·문산·도라산 보충 및 범위 조정 |
| 전라선 | 9 → 11 | 1.00 → 0 | 여천·여수엑스포 좌표 및 범위 수정 |
| 태백선 | 7 → 8 | 1.00 → 0 | 백산 보충 |
| 중앙선 | 20 → 22 | 0.667 → 0 | 서원주 보정·모량 보충 |

가야선의 범일 보충 후 동해선 기점의 외삽 기울기가 바뀌므로 부산진도 확인해 보충했다. 동해선의 최대 외삽 비율도 0이 됐다.
중부내륙선도 부발·충주·문경의 닻 3개로 양 끝 외삽을 없앴다. 실측 닻 2개 미만인 노선은 49개에서 43개로 줄었다. 가상 닻을 추가하는 일반 알고리즘 변경과 보류된 UI 확대/라벨 정책은 이번 수정에 포함하지 않았다.

## 검증

- `gradlew.bat compileJava test`: 9개 테스트 통과. 기존 서비스/부팅 4개와 신규 좌표 회귀 5개.
- 새로 보충/보정한 모든 역이 인메모리 DB의 최종 화면 좌표까지 반영되는지 역투영해 확인했다.
- 다른 노선의 지역 검사에서 제외되는 공유역 김천이 실측 위치를 유지하고, 노선 순서가 바뀌어도 결과가 같은지 확인했다.
- 구/신 문경역이 서로 다른 ID·좌표·노선 소속으로 시딩되는지 확인했다.
- 정부 원본 및 앞선 삼척선 보충까지 기존 218행이 변경되지 않았음을 `git show HEAD:...`와 비교했다.
- 현재 실행 중인 사용자 앱의 재시작이나 브라우저 육안 검증은 수행하지 않았다. **앱을 완전히 정지하고 재시작해야 반영된다.** 테스트는 파일 DB와 분리된 인메모리 DB에서 새 시딩/레이아웃까지 실행했다.

## 다음 작업 (2026-09-21 갱신 시점 기준)

1~5번 항목(경부고속선/경부선 재확인, 수원·오산 등 지역 경계 오탐, 중부내륙선·문경선 중간역, 영동선·호남선 외삽, 공유역 영향 노선)은
위 "2026-09-21 후속 갱신"에서 설명한 726개 역 전수 대조로 해소됐다 — 아래 진행표에서 대부분 노선이 역 수와 외부 출처 대조 수가 같다.
남은 항목은 다음 두 가지뿐이다.

1. 야음역(울산항선, 폐역): 위키백과·나무위키·OSM 어디에도 좌표가 없다. 옛 역 부지는 현재 사거리/주유소로 바뀌어 도로명주소 역추적도 정밀하지 않다. 추측값을 넣지 않고 `pending`으로 유지한다.
2. 군산화물선분기역(군산화물선, 폐선): 장항선과의 분기점이라는 설명 외에 독립된 역 문서나 좌표 출처가 없다. `pending`으로 유지한다.

두 역 모두 소속 노선이 이미 확보한 나머지 앵커만으로 외삽되므로 화면 배치에 큰 영향은 없지만(두 노선 다 폐선/폐역 구간), 실제 좌표는 여전히 미확정이다.

아래 표는 `python scripts/audit-line-anchors.py --markdown`으로 재생성한다(Windows 콘솔은 cp949라 `—` 문자가 깨지므로 UTF-8로 리다이렉트해서 읽을 것). **유효 닻**은 현재 노선의 지역 검사를 통과한 수이며, **외부 출처 대조**는 이번 감사 CSV에 기록한 수다. 다른 노선에서 승인된 공유역은 최종 좌표가 고정되므로 '지역 검사 제외'가 곧 최종 좌표 오류라는 뜻은 아니다. `--json`에는 누락/제외 역명도 나온다.
